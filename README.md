# Abdul Rehman - Shopify Portfolio v2

## Replace your current site
Upload ALL files from this folder into the same GitHub folder as your existing index.html, replacing index.html, style.css, app.js and vercel.json. Add product.html, collection.html, project.html and data.js as well. Vercel will redeploy the connected production branch automatically. Framework: Other. Build command: none. Output directory: a single dot (.). Root directory: the folder containing index.html. Do not upload only this ZIP.

## Pages
- index.html: portfolio with photographic project showcases, expertise, contact brief.
- project.html?edit=women or ?edit=men: original project concept detail pages.
- collection.html?edit=women or ?edit=men: storefront demos with category and price sorting.
- product.html?item=evening, city, wardrobe, or tailored: dedicated product page with gallery, size guide, variant preview, quantity and demo bag.

## Important content details
All projects are clearly labeled self-initiated concepts, not paid client work. No reference-site names, logos, copy, screenshots, or assets are included. Verify skill/service copy against your actual experience. Contact opens a copyable brief rather than sending email. Replace it with your real contact link if desired.
